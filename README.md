# Codveda Level 3 - Advanced Task 2-NLP-sentiment-Analysis

## Overview
This project is part of the Codveda Advanced Level tasks. It demonstrates the application of advanced machine learning techniques to analyze data, build predictive models, and evaluate their performance.

## Objectives
- Perform data preprocessing and cleaning
- Apply advanced machine learning algorithms
- Evaluate model performance using appropriate metrics
- Visualize insights from the dataset

##  Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Workflow
1. Data Loading
2. Exploratory Data Analysis (EDA)
3. Data Preprocessing
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Visualization
